# Figure captions

**Figure 1.** Age of every dated source that a speaker named, on the day it was cited. Each dot is one source (UK n = 98, Australia n = 63). The horizontal axis is logarithmic. Vertical bars mark medians: 37 days for the UK and 8 days for Australia.

**Figure 2.** What each claim about AI rests on, as a share of each country's claims. "Vague attribution" means a source was gestured at but not identified, such as "experts say". UK: 51% none, 33% named source (n = 335). Australia: 50% none, 31% named source (n = 226).

**Figure 3.** One human reviewer's verdicts on a stratified random sample of 40 coded claims. Bars show counts as a share of each row; rows differ in size because some questions apply only to claims with a source or to incidents. "Is it a claim?" asks whether the coder should have coded the remark at all. One currency ruling the reviewer later withdrew is counted as unsure.
